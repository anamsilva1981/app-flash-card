# App Flash Card

Aplicação Angular mobile-first para estudo com flashcards e repetição espaçada.

## MVP

- Conteúdo inicial sobre Fundamentos de Machine Learning
- Filtro por tópico
- Revisão diária
- Resposta oculta até tentar lembrar
- Avaliação: Não sei, Difícil, Sei e Fácil
- Próxima revisão em 1, 2, 4 ou 7 dias
- Progresso salvo no localStorage

## Executar

    npm install
    npm start

O conteúdo fica no código no MVP: o foco é estudar, não manter uma tela administrativa.
